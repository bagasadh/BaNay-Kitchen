# BaNay Kitchen

Menu catalog and WhatsApp ordering site for **BaNay Kitchen** (homemade pastries and desserts).

## Features
- Product catalog with photos and a cart that sends orders to WhatsApp.
- Responsive layout in plain HTML, CSS, and JavaScript.

## Run Locally

```bash
npm start
```

Open `http://localhost:3000`. Run `npm run build` (or `npm run watch`) after editing `sections/`, `css/`, or `js/`.
